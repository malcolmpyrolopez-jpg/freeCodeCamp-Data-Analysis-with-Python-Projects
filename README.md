# Data Analysis with Python - freeCodeCamp

This repository contains my solutions and projects for the **Data Analysis with Python Certification** from [freeCodeCamp](https://www.freecodecamp.org/). Each project demonstrates data cleaning, processing, statistical analysis, and visualization using core Python data science libraries.

---

## Tech Stack & Libraries
- **Python**
- **Pandas & NumPy** (Data manipulation, cleaning, and mathematical operations)
- **Matplotlib & Seaborn** (Data visualization and statistical plotting)
- **SciPy** (Statistical functions and linear regression)

---

## Projects Overview

### 1. Mean-Variance-Standard Deviation Calculator
- **Objective:** Use NumPy to process a list of 9 digits into a 3x3 matrix.
- **Key Skills:** Matrix manipulation, calculating mean, variance, standard deviation, max, min, and sum across rows, columns, and flattened matrices.

### 2. Demographic Data Analyzer
- **Objective:** Extract and analyze demographic data from the 1994 Census bureau database using Pandas.
- **Key Skills:** Conditional selection, grouping, merging, calculating percentages, and finding correlations between education levels, occupation, and salary brackets.

### 3. Medical Data Visualizer
- **Objective:** Clean and visualize medical examination data to explore the relationship between cardiac disease, body mass index (BMI), blood pressure, and lifestyle choices.
- **Key Skills:** Data cleaning (filtering out incorrect data segments), reshaping dataframes, and creating categorical catplots and correlation heatmaps using Seaborn and Matplotlib.

### 4. Page View Time Series Visualizer
- **Objective:** Visualize time series data tracking website page views on freeCodeCamp.com to identify growth patterns and monthly/yearly seasonality.
- **Key Skills:** Date-time indexing, data filtering, handling outliers, and generating line charts, bar charts, and box plots.

### 5. Sea Level Predictor
- **Objective:** Analyze global sea level change data from 1880 onwards and predict future sea level rises through 2050.
- **Key Skills:** Scatter plots, linear regression modeling using `scipy.stats.linregress`, and generating trend lines to forecast future data points.
